## Why it fits

A terminal workspace for browsing MLflow experiments, comparing runs, inspecting
metrics/artifacts/datasets, and keeping per-experiment views. Shared CLI/TUI target
forms, keyboard navigation, mouse controls, notes, and evidence-based summaries
reduce repeated navigation through an experiment catalog. [README][readme]

**Tradeoffs:** remote tracking uses MLflow's public REST API, while local stores
start a temporary official MLflow server. Local stores and direct cloud artifact
access can therefore need a Python/uv runtime in addition to the Go executable.
This inspected version covers exploration and artifact access; it does not
establish the availability of later serving or model-provisioning work.
[README][readme]
